Ejemplo
Queremos obtener el nombre de alumnos y ciudad de residencia de los laumnos que viven en "San Luis Potosi" o en "Soledad de Graciano Sanchez"
**Expresion**
![Pasted image 20261002151338.png](/img/user/Pasted%20image%2020261002151338.png)
proyeccion -> n
direccion o-

SELECT nombre_alumno, ciudad FROM alumno WHERE ciudad = 'San Luis Potosi'
UNION
SELECT nombre_alumno, ciudad FROM alumno WHERE ciudad = 'Soledad de Graciano Sanchez'


# Ejercicios
1. Mostrar los nombres y appelidos de los profesores que pertenecen al area de "Ciencias de la Computacion" o al area de "Ciencias de la Tierra". Construye nua expresion para cada area academica y utiliza la operacion UNION
	Exquema de relacion: profesor(profesor_id, nombres, appelidos, area)

![Pasted image 20261002151921.png](/img/user/Pasted%20image%2020261002151921.png)

SELECT nombre, apellido FROM profesor WHERE area = 'Ciencias de la Computacion'
UNION
SELECT nombre, apellido FROM profesor WHERE area 'Ciencias de la Tierra'

2. Obtener los nombres y promedios de los alumnos que cursan el semestre 1 o el semestre 2.
	Construye una expresion para cada semestre y utiliza la operacion UNION.
	Esquema de relacion: alumno(alumno_id, nombre, promedio, semestre)

![Pasted image 20261002152253.png](/img/user/Pasted%20image%2020261002152253.png)

SELECT nombre, promedio FROM alumno WHERE semestre = 1
UNION
SELECT nombre, promedio FROM alumno WHERE semestre = 2

3. Listar las materias(nombre y creditos) que sean del area "Civil" o del area "Agroindustrial". Construye una expresion para cada area y utiliza la operacion union.
	Esquema de relacion: materia(materia_id, nombre_materia, creditos, area)

![Pasted image 20261002152645.png](/img/user/Pasted%20image%2020261002152645.png)

SELECT nombre, creditos FROM materia WHERE area = 'Civil'
UNION
SELECT nombre, creditos FROM materia WHERE area = 'Agroindustrial'

4. Obtener los id_grupo y turno de los grupos que tengan turno matutino o vespertino. Construye una expresion para cada semestre y utiliza la operacion UNION.
	Esquema de relacion: inscripcion(id_grupo, turno)

![Pasted image 20261002153051.png](/img/user/Pasted%20image%2020261002153051.png)

SELECT * FROM grupo WHERE turno 'matutino'
UNION
SELECT * FROM grupo WHERE turno 'vespertino'

4. Mostrar las inscripciones correspondientes al semestre "2025-2026/II" o al semestre "2026-2027/I". Construye una ezpresion para cada semestre y utiliza la operacion UNION.
	Esquema de relacion: inscripcion(id_alumno, id_materia, semestre, calificacion)

![Pasted image 20261002153533.png](/img/user/Pasted%20image%2020261002153533.png)

SELECT * FROM inscripcion WHERE semestre = '2025-2026/II' 
UNION
SELECT * FROM inscripcion WHERE semestre = '2026-2027/I'
