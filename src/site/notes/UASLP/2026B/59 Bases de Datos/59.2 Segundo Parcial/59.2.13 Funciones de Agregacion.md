Las funciones de agregacion (tambien llamadas funciones de resumen o funciones estadisticas) son operaciones que permiten calcular valores globales o resumidos a partir de un conjunto de tuplsa (filas) de una relacion.

Mientras que las operaciones tradicionales (σ, ) trabajan sobre tuplas individuales, las funciones de agregacion operan sobre conjuntos de tuplas, produciendo un solo valor de resultado o una tupla por grupo


| x   |
| --- |
| 1   |
| 1   |
| 3   |
| 4   |
| 4   |
| 11  |

| Funcion de agregacion | Operacion         | Resultado |
| --------------------- | ----------------- | --------- |
| sum(x)                | Suma              | 24        |
| avg(x)                | Media de valores  | 4         |
| count(x)              | Conteo de valores | 6         |
| min(x)                | Valor minimo      | 1         |
| max(x)                | Valor maximo      | 11        |

Ejemplo:

Relacion
	alumno(id_alumno, nombre_alumno, carrera, semestre, promedio)
	**𝒢<sub>avg(promedio)</sub>(alumno)**
El resultado de la expression, es una relación con un único atributo, que contiene una sola fila con un valor numero correspondiente al promedio de todos los promedios de todos los alumnos

| avg(prom) |
| --------- |
| 8.7       |

Ejemplo con agrupacion:
Existen ocasiones en las que se desea aplicar las unciones de agregación a un único conjunto de tuplas, sino a grupos de conjuntos de tuplas

<sub>carrera</sub> **𝒢** <sub>avg(promedio)</sub>(alumno)

| carrera               | avg |
| --------------------- | --- |
| Computacion           | 8.9 |
| Sistemas Inteligentes | 8.4 |
| Civil                 | 9.1 |

Los siguientes ejercicios están diseñados para aplicar las funciones de agregación sobre las tablas de tu esquema base:

alumno(id_alumno, nombre_alumno, apellidos_alumno, carrera, semestre, promedio, ciudad)
inscripcion(id_akumno, id_grupo, semestre, calificacion)
profesor(id_profesor, nombre_profesor, apellido_profesor, area, salario)
grupo(id_grupo, clave_materia, turno, salon, cupo)

1. **Calcular el promedio general de todos los alumnos registrados**
	𝒢 avg(promedio)(alumno)

2. **Obtener el promedio de calificaciones por cada carrera**
	carrera 𝒢 avg(promedio)(alumno)
	
3. **Mostrar el salario máximo y mínimo de los profesores agrupados por area académica**
	area 𝒢 min(salario), max(salario) (profesor)
	
4. **Contar cuantos alumnos se encuentran inscritos en cada semestre**
	semestre 𝒢 count(id_alumno) (inscripcion)
	
5. **Calcular el promedio de cupo de los grupos en turno matutino y vespertino**
	turno 𝒢 avg(cupo)(grupo)

6. **Calcular cuantos alumnos viven en cada ciudad registrada**
	ciudad 𝒢 conut(id_alumno)(alumno)
	
7. **Obtener la suma total de salarios que se pagan a los profesores en cada area**
	area 𝒢 sum(salario)(profesor)
	
8. **Determinar el promedio de calificacion de los alumnos en cada grupo**
	id_grupo 𝒢 avg(calificacion)(inscripcion)
	
9. **Obtener el promedio mas alto registrado entre los alumnos de cada carrera**
	carrera 𝒢 max(promedio)(alumno)
	
10. **Calcular la suma de cupos de todos los grupos, agrupados por su turno (matutino o vespertino)**
	turno 𝒢 sum(cupo)(grupo)
