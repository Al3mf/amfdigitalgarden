El producto cartesiano (x) es una de las operaciones fundamentales del algebra relacional.
Se utiliza para combinar todas las tuplas (filas) de una relacion con todas las tuplas de otra relacion, sin aplicar ninguna condicion de coincidencia
Su nombre proviene del producto cartesiano entre conjuntos en matematicas y costituye la base para otras operaciones mas avanzadas, como la reunion (join) y las reuniones externas

Sean dos relaciones:
$$
R1(A1,A2,...,An)
$$
$$
R2(B1, B2,...,Bn)
$$
El producto cartesiano se define como:
	*R1 x R2 = {t1 U t2 | t1 E R1 y t2 E R2}*

>[!Note]

Si R1 tiene n1 tuplas y R2 tiene n2 tuplas, entonces el resultado R1 x R2 tendra:
	*n1 x n2 tuplas*
El esquema de atributos resultante sera la concentracion de los esqueas de ambas relaciones:
	*Atriubtos(R1xR2) Atributos(R1) U Atributos(R2)*
En la practica, si hay atributos con el mismo nombre, se renombran temporalmente como R1.A, R2.A para evitar ambigüedades


# Propiedades del Producto Cartesiano
1. No conmutativa
	R1 x R2 =/ R2 x R1
	El orden afecta el nombre de los atributos
2. Asociativa
	(R1 x R2) x R3 = R1 x (R2 x R3)
3. Aumenta la dimensionalidad
	El numero de columnas del resultado es la suma de las columnas de ambas relaciones
4. Base para el JOIN
	El producto cartesiano no es el primer paso en la construcción de una reunion natural


# Interpretacion del Producto Cartesiano
El producto cartesiano no impone ninguna relacon entre los datos de ambas tablsa; simplemente combina todas las posibilidades.
Por ello, es una operacion de gran tamano, pero poco util por si sola en consultas practicas.
Sin embargo, se vuelve esencial cuando se filtra despues con una operacion de seleccion (o-), lo que da origen a un JOIN.

- alumno x materia
SQL
- SELECT * FROM aluno, materia;
- SELECT * FROM alumno CROSS JOIN materia;

# Ejemplo 2 - Producto Cartesiano
Calcular el numero de tuplas que resultara de alumno x grupo si:
- alumno tiene 50 registros
- grupo tiene 10 registros
Solucion:
- 50 x 10 = 500 tuplas
Conclusion:
El producto caresiano puede generar grandes volumenes de datos, por eso se usa con precaucion u nomrmalmente acompanado de una seleccion
