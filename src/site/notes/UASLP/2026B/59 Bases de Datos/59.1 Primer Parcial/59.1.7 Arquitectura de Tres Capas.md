## Cuales son sus componentes?
- PRESENTACION
	La "caja". Es la pagina web o movil

## Comparativa

| Caracteristica | 2 Capas (Cliente-Servidor)                                               | 3 Capas (Multinivel)                                            |
| -------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------- |
| Mantenimiento  | Dificil.Hay que actualizar la app en cada computadora de los usuarios    | Facil. Se actualia el servidor central y todos ven los cambios  |
| Seguridad      | Baja. La computadora del usuario tiene acceso directo a la base de datos | Alta. La base de taos esta oculta detras de la capa de negocios |
| Rendimiento    |                                                                          |                                                                 |
| Costo Inicial  |                                                                          |                                                                 |
## Reglas de Oro
1. Reponsabilidad Unica: Cada capa hace una sola cosa
2. Abstracciones: Contratos de comunicacion. Ocultan la complejidad
3. Comunicacion Estricta: Regla de no saltar

## Ejemplo de Tres Capas
**Apicacion de Uber**
- Capa 1 (Presentacion): Tu celular. Solo uestra el mapa y botones. No calcula precios
- Capa 2 (Logica): Servidores de Uber. Reciben tu ubicacion, revisan el trafico, calculan la "tarifa dinamica" y buscan conductor
- Capa 3 (Datos): Servidores de almacenamiento masico. Guardan tu perfil, tarjetas e historial

## Beneficios
Por que trabajamos asi?
- Mantenimiento (Bug Tracking): Aislamiento de errores
- Cambios drasticos sin impacto: Flexibilidad
- Escalabilidad: Crecimiento independiente
