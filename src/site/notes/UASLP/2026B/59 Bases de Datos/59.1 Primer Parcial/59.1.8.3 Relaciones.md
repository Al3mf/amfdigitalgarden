Una **relación** es la asociacion entre dos o mas entidades que tiene sentido dentro del modelo.

# Grado de una relacion
El **grado** se refiere al numero de entidades que participan en la relacion:
- Binaria: 2 Entidades
- Ternaria: 3 Entidades
- N-naria: mas de 3 Entidades

>[!Note] Relacion
>Se representan como **rombos** en el diagrama E-R
>En el rombo va una **accion verbal**

# Que tipo de palabra va en las relaciones?
En los diagramas E-R, dentro del **rombo** (que representa la relación) se coloca un **verbo o una frase verbal** que **exprese la accion o vinculo** entre las entidades.

Características de las palabras en las relaciones:
1. Verbos en infinitivo o en presente -> reflejan accion:
	Realiza
	Incluye
	Contiene
	Dirige
	Compra
2. Expresan asociación, no atributos -> es decir, no describen características sino vínculos
3. Deben ser claras y comprensibles -> evitar ambiguedades
	Ejemplo:
	Mejor usar -> Alumno - **Inscrito** - Curso
	que algo generico como -> Alumno - **Relacion** - Curso
4. En relaciones debiles -> se suele usar tambien una frase que exprese dependencia:
	DetalleFactura 

# Ejemplos relaciones
Contexto: Tienda en linea
Cliente - Realiza - Pedido
Pedido - Contiene - Producto
Empleado - atiende - Pedido

Contexto: Universidad
Alumno - Inscrito - Curso
Profesor - Imparte - Curso
Carrera - Incluye - Curso

# Tipos de Relaciones (Cardinalidad)
Uno a uno (1:1): Cada entidad de un conjunto se relaciona con una sola entidad del otro conjunto.

Ejemplo: Una persona solo puede tener un pasaporte y un pasaporte solo lo puede tener una persona
	Persona - Tiene - Pasaporte
	    (1,1) - 1:1 - (1,1)
