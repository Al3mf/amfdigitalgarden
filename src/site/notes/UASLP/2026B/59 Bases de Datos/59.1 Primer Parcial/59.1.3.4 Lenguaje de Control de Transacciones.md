Controla las transacciones para asgurar la integridad de los datos
## COMMIT
- Guarda de forma permanente los cambios relizados en la transaccion
## ROLLBACK
- Revierte los cambios realiados en la transaccion actual
## SAVEPOINT
- Crea un punto de guardado dentro de una transacción para hacer rollback parcial
