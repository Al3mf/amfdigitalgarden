Un **atributo** describe una característica de la entidad.

Ejemplo: La entidad **Alumno** puede tener matricula, nombre, carrera
Entidad: Alumno
Atributos
- Matricula
- Nombre
- Carrera

>[!Note] Atributos
>En el diagrama E-R se representan con **ovalos**


# Tipos de Atributos en el Modelo E-R
## Atributo Clave
Identifica de manear unica a cada entidad...

Ejemplo: **matricula** para un alumno, **empleado_id** para un empleado, **IBSN** para un libro

>[!Note] Atributo Clave
>En el diagrama E-R se representan con **ovalos**, en donde el **atributo** o **conjunto de atributos**

## Atributo Simple
No se puede dividir en partes mas pequenas.

Ejemplo: fecha_nacimiento


## Atributo Compuesto
Puede descomponerse en atributos mas basicos.

Ejemplo: **nombre_completo** -> nombre + apellido_pat + apellido_mat 
Ejemplo: **direccion** -> calle + num + ciudad + estado

>[!Note]
>En el diagrama E-R **atributos simples** que lo **componen** se representan como un **ovalo secundario, conectado** al **ovalo del atributo compuesto**

## Atributo Multivalorado
Puede tener mas de un valor para la misma entidad.

Ejemplo: **telefonos** de un cliente, **idiomas** que habla un empleado

>[!Note] Atributo Multivalorado
>En el diagrama E-R se representan con un **ovalo doble**

## Atributo Derivado
Su valor se calcula a partir de otros atributos, no se almacena fisicamente en la base de datos, sino que se calcula cuando es necesario.

Ejemplo: **edad** puede derivarse de **fecha_nacimiento**
Ejemplo: **an;os antiguedad** se obtiene a partir de la **fecha_contratacion**

>[!Note] Atributo Derivado
>En el diagrama E-R se representan como un **ovalo punteado**
