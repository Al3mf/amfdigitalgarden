Buenos Aires SA elabora tres tipos de aire acondicionado caseros: el modelo economico (modelo E), el modelo standard (modelo S), y el modelo de lujo (modelo L). los dividendos por articulo son: 63, 95 y 135 dolares respectivamente los requerimentos minimos para producir cada uno de estos modelos estan dados por la tabla inferior. para le procimo pedido, la empresa cuenta con 200 ventiladores, 320 bobinas de enfriamiento y 2400 horas para la fabricacion

|          | No. de Ventiladores | No. Bobinas | Tiempo de Manufactura (hrs) |
| -------- | ------------------- | ----------- | --------------------------- |
| Modelo E | 1                   | 1           | 8                           |
| Modelo S | 1                   | 2           | 12                          |
| Modelo L | 1                   | 4           | 14                          |

|              | E   | S   | L   |      |
| ------------ | --- | --- | --- | ---- |
| ventiladores | 1   | 1   | 1   | 200  |
| bobinas      | 1   | 2   | 4   | 320  |
| tiempo (hrs) | 8   | 12  | 14  | 2400 |
|              | 63  | 95  | 135 |      |

a) utilizando la programacion lineal, determina el volumen maximo que puede producis de cada no de los modelos, para maximizar su fanancia


Max 63x1 + 95x2 + 135 x3
ST
x1 + x2 + x3 <= 200
x1 + 2x2 + 4x3 <= 320
8x1 + 12x2 + 14x3 <= 2400
