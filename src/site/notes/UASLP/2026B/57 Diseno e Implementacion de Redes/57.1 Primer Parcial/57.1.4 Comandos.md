Click on Switch -> CLI


| Comando                                                    | Descripcion                                                                                     |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| ?                                                          | Abre Exec Commands que es un mini menu de comandos de ayuda                                     |
|                                                            | ">" Modo Usuario                                                                                |
| enable                                                     | "#" Modo Privilegiado                                                                           |
| enable+?                                                   | Abre Exec Commands del modo privilegiado                                                        |
|                                                            | Si presionas Enter avanzas linea por linea                                                      |
|                                                            | Si presionas Space se muestran las siguientes 22 lineas                                         |
|                                                            | Si presionas Esc finaliza el comando                                                            |
| show                                                       |                                                                                                 |
| show running-config                                        | Muestra la configuracion actual                                                                 |
| **config terminal**                                        | Configuramos la terminal en modo privilegiado                                                   |
| hostname + " "                                             | Cambia el nombre del host "hostname cosmic1"                                                    |
| exit                                                       | Se sale de la pantalla en la que estes                                                          |
| show clock                                                 | Muestra el reloj                                                                                |
| clock set hh:mm:ss 1-31 MONTH Year                         | Configura el reloj                                                                              |
| copy running-config startup -config                        | Copia la configuracion / Guarda la configuracion en el dispositivo                              |
| connect copy                                               |                                                                                                 |
| **conf term -> line con 0**                                | Entra al modo de configuracion de linea                                                         |
| password "password"                                        | crea una contrasena para modo consola                                                           |
| login                                                      | habilita un login para modo consola                                                             |
| conf ter -> enable password "password"                     | Crea una contrasena para modo privilegiado                                                      |
| service password-encryption                                | Encripta todas las contrasenas (nivel de encripcion bajo)                                       |
| no service password-encryption                             | Elimina la encripcion de contrasenas, pero NO elimina la encripcion actual, solo para el futuro |
| conf t -> enable secret "password"                         | Encriptala contrasena indicada con un nivel mas alto de encripcion                              |
| conf t -> interface vlan1                                  | entra al modo configuracion de vlan1                                                            |
| ip address                                                 | Modificamos la ip del  dispositivo (ex. 20.1.1.3 255.0.0.0)                                     |
| interface vlan1 -> no shutdown                             | Prendemos la interfaz                                                                           |
| ping "ip"                                                  | hace ping a la ip configurada                                                                   |
| telnet "ip"                                                | hace telnet a la ip configurada                                                                 |
| conf t -> username "user" secret "password"                | configura un user                                                                               |
| username " " privilege 0-15 secret " "                     | configura un admin user para enable                                                             |
| conf t -> line vty 0 15                                    | configura desde la linea vty 0 a la 15                                                          |
| login local                                                | configura login local de linea 0 a 15                                                           |
| conf t -> crypto key generate rsa general-keys modulus " " | Encripta un modulo en x cantidad de niveles / bits                                              |
| ip domain name " "                                         | crea un dominio en la lm                                                                        |
| line vty 0 15 -> transport input ssh                       | activa ssh                                                                                      |
| ssh -l "username" target (ip)                              |                                                                                                 |


> [!NOTE]
> IP - Internet Protocol
