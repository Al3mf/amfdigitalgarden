Click on Switch -> CLI


| Comando                             | Descripcion                                                        |
| ----------------------------------- | ------------------------------------------------------------------ |
| ?                                   | Abre Exec Commands que es un mini menu de comandos de ayuda        |
|                                     | ">" Modo Usuario                                                   |
| enable                              | "#" Modo Privilegiado                                              |
| enable+?                            | Abre Exec Commands del modo privilegiado                           |
|                                     | Si presionas Enter avanzas linea por linea                         |
|                                     | Si presionas Space se muestran las siguientes 22 lineas            |
|                                     | Si presionas Esc finaliza el comando                               |
| show                                |                                                                    |
| show running-config                 | Muestra la configuracion actual                                    |
| config terminal                     | Configuramosla terminal en modo privilegiado                       |
| hostname + " "                      | Cambia el nombre del host "hostname cosmic1"                       |
| exit                                | Se sale de la pantalla en la que estes                             |
| show clock                          | Muestra el reloj                                                   |
| clock set hh:mm:ss 1-31 MONTH Year  | Configura el reloj                                                 |
| copy running-config startup -config | Copia la configuracion / Guarda la configuracion en el dispositivo |
> [!NOTE]
> IP - Internet Protocol
