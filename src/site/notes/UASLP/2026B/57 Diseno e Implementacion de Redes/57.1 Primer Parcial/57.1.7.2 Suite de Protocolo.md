# Suite de Protocolo TCP/IP
TCP/IP Es el conjunto de protocolos utilizado por Internet e incluye muchos protocolos.
TCP/IP es:
- Un conjunto de protoclolos estandar abierto que esta disponible gratuitamente ara el publico y que puede ser utilizado por cualquier proveedor
- Un protocolo basado en estandares es un proceso que recibio el aval del sector de redes y fue aprobado por una organizacion de estandarizacion

# Proceso de comunicacion TCP/IP
Un servidor web encapsulando y enviando una pagina web a un cliente
Un cliente que desencapsula la pagina web para el navegador web
