# Destino en la misma red
Hay dos direcciones principales asignadas a un dispositivo en una LAN Ethernet:
- Direccion fisica de capa 2 (la direccion MAC): se utiilza para comunicaciones NIC a NIC en la misma red Ethernet
- Direccion logica de capa 3 (la direccion IP): Se utiliza para enviar el paquete desde el dispositivo origen al dispositivo destino
