# IPv6 Formatos de direcciones
- Las direcciones IPv6 tienen 128 bits de longitud y estan escritas en hexadecimal
- Las direcciones IPv6 no distinguen entre mayusculas y minusculas, u pueden escriirse en minusculas o en mayusculas
- El formato preferido para escribir una direccion IPv6 es:
	x: x: x: x: x: x: x: x:
	donde cada "x" 

# Regla 1 - Omitir el cero inicial
La primera regla para ayudar a reducir la notacion de las direcciones IPv6 es omiti los 0s iniciales
Ejemplos:
- 01ab se puede representar como 1ab
- 09f0 se puede representar como 9f0
- 0a00 se puede representar como a00
- 00ab se puede representar como ab

>[!Note]
>Esta regla solo es valida para los ceros iniciales, y NO para los ceros finales; de lo contrario, la direccion seria ambigua


| Tipo        | Formato                                                               |
| ----------- | --------------------------------------------------------------------- |
| Recomendado | 2001: **0**db8: **000**0:1111: **000**0: **000**0: **000**0: **0**200 |
| Comprimido  | 2001: db8: 0: 1111: 0: 0: 0: 200                                      |

# Regla 2 - Dos puntos
Los puntos dobles pueden reemplazar cualquier cadena unica y contigua de uno o mas segmentos de 16 bits que esten compuestas solo por ceros

>[!Note]
>Los dos puntos dobles(::) se pueden utilizar slamente una vez dentro de una direccionl de lo contrario, habria mas de nua direccion resultante posible

| Tipo        | Formato                                                               |
| ----------- | --------------------------------------------------------------------- |
| Recomendado | 2001: **0**db8: **000**0:1111: **000**0: **000**0: **000**0: **0**200 |
| Comprimido  | 2001:db8:0:1111::200                                                  |
