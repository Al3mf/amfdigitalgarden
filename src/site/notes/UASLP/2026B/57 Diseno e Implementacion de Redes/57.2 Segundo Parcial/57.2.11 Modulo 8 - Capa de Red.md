# Características de la capa de red
Proporciona servicios para permitir que los dispositivos finales intercambien dato
- IP version 4 y version 6 son los principales protocolos de comunicación de la capa de red
- La capa de red realiza cuatro operaciones básicas:
	- Direccionamiento de terminales
	- Encapsulamiento
	- Routing
	- Des encapsulamiento

# Encapsulamiento IP
- IP encapsula el segmento de la capa de transporte
- IP puede utilizar un paquete IPv4 e IPv6 y no afectar el segmento de capa 4
- El paquete IP sera examinado por todos los dispositivos de capa 3 a medida que atraviese la red
- El direccionamiento IP no cambia de origen a destino

>[!Note]
>NAT cambiara el direccionamiento, pero se discutira en un modulo posterior

# Características de IP
IP esta destinado a tener una sobrecarga baja y puede describirse como:
- Sin conexión
- Servicio mínimo
- Independiente de los medios

# Independencia de Medios
IP no es confiable
