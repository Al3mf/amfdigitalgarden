# La Trama
Los datos son encapsulados por la capa de enlace de datos con un ecabezado y un remolque para formar una trama. 
Una trama de enlace de datos consta de tres partes:
- Encabezado
- Datos
- Trailes

# Campos de Trama

| Campo                  | Descripcion                                       |
| ---------------------- | ------------------------------------------------- |
| Trama de Inicio y Alto | Identifica el inico y el final de la trama        |
| Direccionamiento       | Indica los nodos de origen y destino              |
| Tipo                   | Identifica el ptrotocolo de 3 encapsulado         |
| Control                | Identifica los servicios de control de flujo      |
| Datos                  | Contiene la carga ytil de la trama                |
| Deteccion de Errores   | Se utiliza para determinar errores de transmision |

# Direcciones de Capa 2
- Tambien se conoce como una dirección física
- Contenido en el encabezado de la trama
- Se utiliza solo para la entrega local de una trama en el enlace
- Actualizado por cada dispositivo que reenvía la trama

# Tramas LAN y WAN
La topología lógica y los medios físicos determinan el protocolo de enlace de datos utilizando:
- Ethernet
- 802.11 inalambrico
- Point-to-Point (PPP)
- Control de enlace de datos de alto nivel (HDLS, High-Level Data Link Control)
- Frame Relay
