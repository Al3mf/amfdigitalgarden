### Nivel de vistas
El nivel mas elevado de abstraccion solo describe parte de la base de datos. El nivel de abstraccion de vistas existe para simplificar su interaccion con el sistema
### Nivel logico
El nivel describe que datos se almacenan en la base de datos y que relacion s existen entre esos datos
### Nivel fisico
El nivel mas bajo de abstraccion describe como se almacenan realmente los datos
