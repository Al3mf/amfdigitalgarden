Sirve para insertar, consultar, actualizar y eliminar datos dentro de las tablas:
## SELECT
- Recupera datos de una o mas tablas
## INSERT
- Inserta nuevos registros
## UPDATE
- Modifica datos existentes
## DELETE
- Elimina registros
