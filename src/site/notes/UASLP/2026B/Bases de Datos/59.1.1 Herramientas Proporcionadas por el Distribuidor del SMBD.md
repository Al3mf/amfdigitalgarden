SMBD - Sistema Manejador de Bases de Datos
- IMPORTAR/EXPORTAR: Incoroporacion nde datos y exportacion de datos
- MONITOREO: Monitorear el uso y el funcionamiento de la base de datos
- ANALISIS ESTADISTICO: Programas de analisis estadistico para examinar las prestaciones o las estadisticas de utiliacion
- REORGANIZACION DE INDICES: Reorganizacion de las estructuras de los indices
- CONSOLIDAD ESPACIO: Herramientas para aprovechas el espacio dejado en el almacenamiento fisico por los registros borrados y que consoliden el espacio liberado para reutiliarlo cuando sea necesario
