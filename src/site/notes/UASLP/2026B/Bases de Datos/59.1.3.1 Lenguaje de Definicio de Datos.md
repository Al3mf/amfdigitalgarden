Se utiliza para crear, modificar y elimintar la estructura de la base de datos
## CREATE
	Crea objetos de la base de datos (Tablas, vistas, indices, esquemas)
## ALTER
	Modifica la estructura de un objeto existente 
	(Agregar columnas, cambiar tipos de datos)
## DROP
	Elimina objetos de la base de datos
## Truncate
	Vacia todos los registros de una tabla sin borrar su estrctura
## RENAME
	Cambia el nombre de un objeto
